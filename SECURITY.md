# Security policy

## Supported versions

Security fixes go into the latest release on PyPI.

## Reporting a vulnerability

Please do not open a public issue. Email dsaran@motifplatforms.com with a description, the affected version and steps to reproduce. You will get a reply within five working days, and a fix or a plan within 30 days of confirmation.

The kit opens untrusted Office files, so reports about malformed .docx, .pptx or .xlsx files that cause crashes, hangs or unsafe XML parsing are especially welcome.
