# board-memo · Q3 results memo for the board

Northwind Outdoor (a fictional company) closed its third quarter. Using `inputs/q3_results.csv`, write a short Word memo
to the board.

The memo must:

1. Be titled **Q3 2026 results**.
2. Open with a **Summary** section that states revenue, gross margin and EBITDA for the quarter.
3. Include a table of the four metrics in the file (revenue, gross margin, operating expenses, EBITDA), each with its
   quarter-on-quarter change.
4. Have a **Risks** section with at least two risks, as a bulleted list.
5. Cite the source file under the table.

## Output contract

- Save one file: `board_memo.docx`.
- Use Word's own heading styles for section titles and Word's own list formatting for bullets.
- Leave no tracked changes or comments in the file.
